# Royal Enfield Himalayan 450 (Euro 5+) - Catálogo de Diagramas e Peças

Catálogo completo extraído diretamente do Partsbook da **Hitchcocks Motorcycles**:
[Link original Hitchcocks](https://www.hitchcocksmotorcycles.com/partsbook/492/2026-450-himalayan-euro-5)

---

## 📁 Estrutura de Arquivos

- **`index.html`**: Visualizador interativo e offline para navegador. Permite navegar pelos diagramas, dar zoom nas ilustrações, visualizar a tabela de peças correspondente e fazer buscas instantâneas por Part Number (SKU) ou nome da peça em toda a motocicleta.
- **`all_parts_himalayan_450.csv`**: Planilha mestre contendo todas as **1.256 peças catalogadas** com as seguintes colunas:
  - `Diagram_Number` (Número do diagrama)
  - `Diagram_Label` (Rótulo original)
  - `Diagram_Name` (Nome da seção/conjunto)
  - `Position` (Posição no diagrama, ex: A1, 1, 2, etc.)
  - `Part_Number_SKU` (Código da peça / Part Number)
  - `Part_Name` (Nome da peça)
  - `Quantity` (Quantidade necessária)
  - `Notes` (Informações de substituição/superseded, observações)
  - `Diagram_Image_File` (Nome do arquivo de imagem do diagrama)
  - `Store_URL` (Link direto para a peça na loja)
  - `Page_URL` (Link da página original no catálogo)
- **`partsbook_himalayan_450.json`**: Base de dados estruturada completa em JSON.
- **`diagrams/`**: Pasta contendo os **52 diagramas em alta resolução** (totalizando ~43.6 MB).
- **`csv_by_diagram/`**: Pasta com 52 arquivos CSV individuais, um para cada diagrama.

## 💡 Como Usar

1. **Visualizador Interativo:**
   - Dê um duplo clique no arquivo [`index.html`](index.html) para abri-lo em qualquer navegador (Chrome, Edge, Firefox).
   - O visualizador funciona **100% offline**, sem necessidade de internet.
   - Use o campo de busca global para digitar qualquer Part Number ou termo (ex: "stator", "pad", "filter") e ver onde a peça se encaixa.
2. **Planilha Excel / Google Sheets:**
   - Abra o arquivo [`all_parts_himalayan_450.csv`](all_parts_himalayan_450.csv) para filtrar, ordenar ou cruzar dados.
